# Contributing

Keep the package small. A new profile needs exact target IDs, primary sources with review dates, concrete adaptation rules, preservation boundaries, and an honest evidence label. Do not generalize behavior from a model family name or claim token reduction as task improvement.

Add aliases only when their meaning is established. Unknown models should continue to fall back to generic guidance. Do not add credential scanning or global runtime detection files. Reproduce a reported failure with the source skill, target identity, host/version, and expected invariant; remove private content first.

Run the local validator and unit tests. Behavioral evaluations on every supported model are not a release requirement; mark untested profiles clearly. Keep public receipts free of personal paths, credentials, and full host system prompts. The project is MIT; third-party fixtures retain their original licenses.
